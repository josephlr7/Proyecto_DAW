========================================================================
             GUIA DE PRUEBAS EN POSTMAN - GESTION DE LABORATORIOS
========================================================================

CONFIGURACION GENERAL EN POSTMAN:
---------------------------------
- Para las peticiones POST y PUT, configure en la pestaña Headers:
  Key: Content-Type
  Value: application/json
  
- Para las peticiones que requieren token, vaya a la pestaña Authorization:
  Type: Bearer Token
  Token: (Pegue el token JWT copiado en el Paso 2)

========================================================================
PASO 1: REGISTRAR UN NUEVO USUARIO (Publico)
========================================================================
METODO: POST
URL: http://localhost:8080/api/auth/registro

BODY (JSON):
{
  "username": "Pruebas",
  "password": "password123",
  "rol": "ADMIN"
}

========================================================================
PASO 2: INICIAR SESION / LOGIN (Publico)
========================================================================
METODO: POST
URL: http://localhost:8080/api/auth/login

BODY (JSON):
{
  "username": "Pruebas",
  "password": "password123"
}

* NOTA: Copie el token devuelto en la respuesta para usarlo en los siguientes pasos.

PASO 8: REGISTRO DE USOS (Requiere Token)
========================================================================

BODY (JSON):
{
  "investigadorId": 2,
  "equipamientoId": 1,
  "tipoInvestigacion": "tesis de pregrado",
  "actividadNombre": "Entrenamiento de red neuronal",
  "horasUso": 150.0,
  "fecha": "2026-08-01",
  "hora": "10:00:00",
  "observacion": "Entrenamiento del modelo completado"
}

B. REGISTRAR USO DE CONSUMIBLE (POST - Resta 250 ml al stock)
